# Security policy

Do not open a public issue for a suspected vulnerability or include private scrim data, access keys, replay files, screenshots, or credentials in a report.

Use GitHub's private vulnerability reporting for this repository. Include the affected version, a minimal reproduction, impact, and relevant logs with secrets and team data removed.

Security fixes are applied to the latest published release. Moe Tracker processes completed replay files and selected post-match screenshots; it must not inject into VALORANT, inspect process memory, automate gameplay, or provide live behavior-changing assistance.
