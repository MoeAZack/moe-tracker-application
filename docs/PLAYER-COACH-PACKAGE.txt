SUPPORT

If anything fails, open Moe Tracker and choose:
Settings -> Device, Sync & Storage -> Export support bundle

Send the resulting MoeTracker-Support-*.zip file to the coach. It contains the
diagnostic event, app/build information, and the latest capture evidence. Also
send the visible MT-... error code if one appears.
